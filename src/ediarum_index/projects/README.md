# Project modules

One module per project: `NAME`, `LABEL`, `DESCRIPTION`, `REGISTER_DIR`, the
entry types it uses (`ENTRY_TYPES`, optional) and the schema `OVERRIDES`. Start from `_template.py` (or `scripts/add_project.sh <slug>`).

How to add and configure one: [`docs/develop/adding-a-project.md`](../../../docs/develop/adding-a-project.md).
